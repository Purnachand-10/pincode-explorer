# Pincode Explorer

A full-stack application to explore pincodes, using a React frontend, Node.js backend for orchestration, and a Python FastAPI service for postal API communication.

## Structure

- `frontend/` - React frontend powered by Vite
- `backend-node/` - Node.js Express server
- `backend-python/` - Python FastAPI service
- `database/` - MySQL database schema and seeding scripts
